# E-Commerce Sales & Customer Analytics

A resume-ready end-to-end data analytics project using Python, Pandas, NumPy, Matplotlib, Seaborn, and Streamlit.

## What it does
- Generates a realistic synthetic e-commerce transaction dataset
- Cleans and validates transaction data
- Calculates revenue, profit, orders, customers, AOV, and growth
- Performs product/category/region analysis
- Performs RFM customer segmentation
- Detects revenue outliers using IQR
- Produces charts and a CSV of business insights
- Provides an interactive Streamlit dashboard

## Run

```bash
pip install -r requirements.txt
python src/generate_data.py
python src/analyze.py
streamlit run src/dashboard.py
```
